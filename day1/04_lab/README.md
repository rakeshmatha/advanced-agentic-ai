# 04: Day 1 Lab

Analyze two customer-service use cases and map each one to:

1. Traditional software, workflow, or agent
2. Prompting, RAG, or fine-tuning
3. REST API or MCP for external capabilities

For every choice, record quality, latency, cost, maintainability, governance,
assumptions, and the trigger for revisiting the decision.

Suggested use cases:

- Answer a question about returns, damaged items, or shipping policy.
- Look up an order and explain its current delivery status.
